# 高校宿舍智能报修管理系统功能说明与验收报告

系统包含学生、宿舍管理员、维修人员和系统管理员四种角色。本次在原有报修业务上补充课程个人实验一、二、四要求，完成登录安全、接口文档、测试与报告；实验三和实验五未纳入本次补充。

## 架构与功能

后端使用Java17、Spring Boot3、MyBatis-Plus和MySQL，采用Controller、Service、Mapper、Entity分层。前端使用Vue3、Vue Router、Axios和Vite，通过REST JSON API访问后端。

| 角色 | 功能 |
|---|---|
| 学生 | 注册登录、提交报修、查询进度、取消、确认评价、未解决反馈 |
| 宿舍管理员 | 审核、派单、宿舍管理、公告和统计 |
| 维修人员 | 查看自己的任务、开始维修、填写结果并提交确认 |
| 系统管理员 | 用户管理、禁用与密码重置、公告、日志和统计 |

报修状态包括PENDING_REVIEW、REJECTED、PENDING_ASSIGN、REPAIRING、PENDING_CONFIRM、COMPLETED、CANCELED。主流程为学生提交、管理员审核派单、维修人员处理、学生确认；Service检查数据归属与状态。

后端19项自动测试、真实MySQL24项HTTP检查、浏览器9项检查均通过，前后端构建成功，可执行jar部署验证成功。详细范围、测试步骤和证据见 [验证结果](验证结果.md)。此结论覆盖本次列出的检查，不表示对所有既有业务进行了穷尽测试。
